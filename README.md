# Stopped 2024Q4 research closure

This branch is a separate, parentless, public-safe selection of existing stopped research. It does not resume research, merge a dataset or confer official completion. The inventory has 480 expected unique country-month IDs, including 12 explicitly excluded units. It records 333 saved-query/core dossier IDs, 327 with query plus URL, extract OR analytical summary and source metadata, and 321 independently reviewed against current evidence hashes. Full explicit excerpt evidence is a separate measure; an analytical summary is not a claim of a captured verbatim excerpt.

INVENTORY.json provides per-unit flags, definitions, lists of every missing ID, duplicates and parse gaps. Counts overlap. Twelve final delivered units have no current independent review. Raw/source/search ledgers, original-source-wording fields, narrative reports, private access and review controls, machine paths, credentials and personal contact identifiers are not published. Whole unsafe files are omitted; originals are not sanitized or modified. Omission is not evidence deletion or a finding of no protests. The full quarter closure is retained in a private local archive with per-file hashes and an archive SHA-256; it was not uploaded to a remote private service.

PUBLICATION_MANIFEST.json identifies every selected source file and its exact original bytes. The source inventory commit is recorded in PROGRESS.json. This public commit has a different hash from the earlier local checkpoint. No original history, main branch or other-quarter material is published by this branch. Use `python verify_publication.py` to reproduce the manifest verification and count consistency checks.
